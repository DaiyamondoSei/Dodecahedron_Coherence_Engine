## Section 0 — How to read this document

Every Edge and every Vertex carries an **Elemental Influence Signature** describing where intervention energy lands when CEN acts on the underlying KPI. Each signature is a per-face 5-element weight distribution summing to 1.0.

- **Edge signature** = 10-tuple (5 elements × 2 faces)
- **Vertex signature** = 15-tuple (5 elements × 3 faces)

**Reading convention:**
- Weight 0.5 = HEAVY emphasis (this element is the primary landing zone)
- Weight 0.3 = MEDIUM emphasis (significant secondary touch)
- Weight 0.1 = LIGHT touch (peripheral element receives some shift)
- Weight 0.05 = TRACE
- Weight 0.0 = element NOT touched by this KPI improvement

**5 elements canonical interpretation (CEN context):**
- **Earth** = material base, codification, structural quantity, tangible artifact
- **Water** = circulation, flow, relational quality, rhythm
- **Fire** = capability ignition, transformation energy, transactional throughput
- **Air** = communication, visibility, articulation, signal projection
- **Ether** = meaning, purpose, transcendent alignment, integration with deeper values

**Detail levels:**
- **HIGH detail (5 KPIs):** Pre-validated E7-11 + V13, plus the three remaining CEN edge-KPIs (E2-10, E10-12, E5-8). Full rationale per face + breath-axis cross-validation + symmetry consideration.
- **MEDIUM detail (45 remaining):** Brief rationale per face. These edges/vertices currently carry NO CEN KPI value (per Lock #8.9 KPI structural-uniqueness count: 29 face-KPIs + 4 edge-KPIs + 1 vertex-KPI = 34 BSC KPIs total). Their signatures are **anticipatory intervention maps** — if CEN later adds a KPI here, this is how the action would distribute.

**Honest tone reminder:** These are RESEARCHER JUDGMENTS. Different researchers might assign different weights. Sensitivity testing (vary by ±10%) is recommended per Lock #8.24 acceptance criterion.
