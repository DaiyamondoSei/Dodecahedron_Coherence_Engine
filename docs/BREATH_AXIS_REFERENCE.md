## What Are Breath Axes?

A dodecahedron has **6 pairs of opposing faces**. In Quannex, these pairs represent **breath axes** - the fundamental rhythms of organizational energy flow.

Just as human breath has inhalation (reception) and exhalation (projection), organizations breathe between opposing domains:

```
                    RECEPTION                    PROJECTION
                        |                            |
        Face A <--------+--------> Face B (opposite)
                        |
                   BREATH AXIS
```

### Geometric Foundation

In a regular dodecahedron, opposing faces are those that:
- Share **zero vertices** (maximally separated)
- Share **zero edges** (no direct connection)
- Are connected only through the **interior** of the form

This geometric opposition maps to organizational polarity - domains that seem opposite but are actually **complementary halves of a single breath**.

## Mathematical Model

### Breath Ratio Calculation

The breath ratio measures the **direction and intensity** of energy flow along an axis:

```javascript
breathRatio = (projectionEnergy - receptionEnergy) / max(receptionEnergy + projectionEnergy, 0.01)
```

| Breath Ratio | Meaning |
|--------------|---------|
| -1.0 | Extreme contraction (all reception, no projection) |
| -0.5 | Moderate contraction (reception dominant) |
| 0.0 | Balanced breath (healthy reciprocity) |
| +0.5 | Moderate expansion (projection dominant) |
| +1.0 | Extreme expansion (all projection, no reception) |

### Breath Health Score

```javascript
// Core calculation
function calculateBreathHealth(receptionFace, projectionFace) {
    const receptionEnergy = extractFaceEnergy(receptionFace);
    const projectionEnergy = extractFaceEnergy(projectionFace);

    // Calculate breath ratio (-1 to +1)
    const ratio = (projectionEnergy - receptionEnergy) /
                  Math.max(receptionEnergy + projectionEnergy, 0.01);

    // Health = how balanced the breath is (0 = perfect balance)
    const imbalance = Math.abs(ratio);

    // Convert to 0-1 score (1 = healthy, 0 = severely imbalanced)
    const health = 1 - imbalance;

    return {
        ratio: ratio,
        health: health,
        status: getBreathStatus(ratio),
        direction: ratio > 0.15 ? 'expansion' : ratio < -0.15 ? 'contraction' : 'balanced'
    };
}
```

### Status Classification

| Ratio Range | Status | Description |
|-------------|--------|-------------|
| -0.15 to +0.15 | Balanced | Healthy reciprocal flow |
| -0.35 to -0.15 or +0.15 to +0.35 | Flowing | Active but sustainable |
| -0.60 to -0.35 or +0.35 to +0.60 | Strained | Needs attention |
| Beyond ±0.60 | Critical | Urgent rebalancing needed |

```javascript
class BreathPatternDetector {
```

#### 2. Predictive Analysis

```javascript
// Future: js/ai/breath/predictive-engine.js

class BreathPredictiveEngine {
    /**
     * Predict breath axis shifts based on upcoming context
     * @param {BreathState} currentState - Current breath readings

    async predict(currentState, context) {

        // - Upcoming product launch → Axis 5 (Perception & Truth) shifts to projection

            prompt: this._buildPredictionPrompt(currentState, context),

        return {
            timeHorizon: prediction.timeframe,
            axisShifts: prediction.shifts.map(s => ({

                currentRatio: currentState.axes[s.axisId].ratio,
                predictedRatio: s.predictedRatio,
                confidence: s.confidence,
                trigger: s.triggerEvent,
                recommendation: s.proactiveAction
            })),
            overallCoherenceTrajectory: prediction.coherenceForecast
        };
    }
}
```

```javascript
class BreathInterventionSuggester {
    /**
     * Suggest interventions for imbalanced axes
     * @param {BreathAxis} imbalancedAxis - The axis needing attention
     * @param {OrganizationalContext} context - Current org state
     * @returns {Intervention[]} Prioritized intervention suggestions

    async suggestInterventions(imbalancedAxis, context) {
        // Intervention types by axis:

        // Axis 1 (Resource Flow):
        //   - Contraction: Activate investor outreach, explore grants
        //   - Expansion: Consolidate runway, pause new initiatives
        //
        // Axis 2 (Substance & Story):
        //   - Contraction: Document IP, capture tacit knowledge
        //   - Expansion: Launch content strategy, speak at events
        //
        // Axis 3 (Being & Doing):
        //   - Contraction: Schedule recovery time, team retreat
        //   - Expansion: Sprint planning, execution focus
        //
        // ... etc for all 6 axes

        const interventions = await this.llm.analyze({
            prompt: this._buildInterventionPrompt(imbalancedAxis, context),
            schema: InterventionSchema
        });

        return interventions.map(i => ({
            action: i.specificAction,
            targetAxis: imbalancedAxis.id,
            targetDirection: i.direction,  // 'increase_reception' or 'increase_projection'
            expectedImpact: i.ratioShift,
            effort: i.implementationEffort,  // 'low', 'medium', 'high'
            timeToEffect: i.timeframe,
            sideEffects: i.otherAxisImpacts,  // May affect other axes
            confidence: i.confidence
        }));
    }
}
```
