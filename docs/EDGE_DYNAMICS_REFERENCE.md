## What Are Edges?

### Geometric Reality

In a dodecahedron:
- Each face is a **pentagon** with **5 edges**
- Each edge is shared by **exactly 2 faces**
- Total edges: **30** (verified by Euler's formula: V - E + F = 2 → 20 - 30 + 12 = 2)

```
THE EDGE: WHERE TWO FACES MEET

              Face A
           ╱         ╲
          ╱           ╲
         ╱             ╲
        ●───────────────●
         ╲             ╱
          ╲    EDGE   ╱
           ╲         ╱
              Face B

The edge is NOT opposition (like breath axes).
The edge is ADJACENCY - neighbors sharing a boundary.

At the edge:
- Face A's territory ends
- Face B's territory begins
- Something must TRANSLATE between them
```

### Organizational Meaning

Edges represent the **interfaces** between organizational domains:

| Geometric Property | Organizational Meaning |
|-------------------|------------------------|
| Boundary between faces | Where one domain's work meets another's |
| Shared by exactly 2 faces | Every interface has exactly 2 stakeholders |
| 5 edges per face | Each domain has 5 neighboring relationships |
| 30 total edges | 30 critical handoff points in the organization |

**The edge is where:**
- **Translation** happens (one domain's output becomes another's input)
- **Friction** can occur (misalignment, miscommunication)
- **Flow** enables (smooth handoffs, mutual understanding)
- **Innovation** emerges (creative tension at boundaries)

## The Nature of Adjacency

### Not Opposition, Not Identity

Breath axes connect **opposing** faces - maximally separated, no shared edges or vertices.
Edges connect **adjacent** faces - immediate neighbors, sharing a boundary.

```
OPPOSITION vs ADJACENCY

Opposition (Breath Axis):           Adjacency (Edge):
Face 1 ←─────────→ Face 11         Face 1 ─── Face 2
(no shared geometry)                (shared edge, possibly vertices)
(complementary polarity)            (neighboring domains)
(dynamic tension)                   (interface dynamics)
```

Adjacent domains are neither the same nor opposite. They are **neighbors** - close enough to interact constantly, different enough to require translation.

### The Five Neighbors

Each face (domain) has exactly 5 adjacent faces. This is geometrically fixed by the pentagon structure:

```
THE FIVE NEIGHBORS OF EACH DOMAIN

                    Neighbor 1
                        │
                   ┌────┴────┐
          Neighbor 5 │ DOMAIN │ Neighbor 2
                   │    X    │
                   └────┬────┘
              Neighbor 4 │ Neighbor 3

Every domain MUST maintain 5 edge relationships.
No more, no less. This is geometric law.
```

**Organizational implication:** No domain is an island. Every domain has exactly 5 interfaces it must manage. Neglecting any edge creates a bottleneck or leak in the system.

## Edge Health: The Interface Quality

### What Makes an Edge Healthy?

A healthy edge allows **smooth transformation** between adjacent domains. Information, energy, and value flow across without getting stuck or lost.

```
EDGE HEALTH SPECTRUM

BLOCKED                                         FLOWING
   │                                               │
   ▼                                               ▼
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│  WALL   │   │ FRICTION│   │  GATE   │   │  FLOW   │
│         │   │         │   │         │   │         │
│ No flow │   │ Partial │   │ Managed │   │ Smooth  │
│ Blocked │   │ Lossy   │   │ Intentl │   │ Natural │
└─────────┘   └─────────┘   └─────────┘   └─────────┘
    0.0           0.3           0.6           1.0

Health Score: 0 (completely blocked) to 1 (perfect flow)
```

### Edge Health Indicators

| Score | State | Symptoms | Example |
|-------|-------|----------|---------|
| 0.0-0.2 | **Wall** | No communication, silos, dropped handoffs | Engineering never talks to Sales |
| 0.2-0.4 | **Friction** | Conflict, blame, delays, information loss | "That's not my job" culture |
| 0.4-0.6 | **Gate** | Formal handoffs, some delays, controlled flow | Documented but slow process |
| 0.6-0.8 | **Flow** | Natural handoffs, mutual understanding | Cross-functional collaboration |
| 0.8-1.0 | **Symbiosis** | Seamless integration, anticipatory support | Teams feel like one organism |

### Measuring Edge Health

```javascript
// Future: js/ai/edge/edge-health.js

/**
 * Calculate health score for an edge between two faces
 *
 * @param {number} faceA - First face ID
 * @param {number} faceB - Second face ID (adjacent to A)
 * @param {EdgeMetrics} metrics - Observable edge indicators
 * @returns {EdgeHealth} Health assessment
 */
function calculateEdgeHealth(faceA, faceB, metrics) {
    // Factor 1: Handoff completion rate
    // How often do things successfully transfer?
    const handoffRate = metrics.successfulHandoffs / metrics.totalHandoffs;

    // Factor 2: Cycle time
    // How long do things wait at the boundary?
    const cycleScore = 1 - Math.min(metrics.avgWaitTime / metrics.targetWaitTime, 1);

    // Factor 3: Information integrity
    // How much is lost in translation?
    const integrityScore = 1 - metrics.informationLossRate;

    // Factor 4: Relationship quality
    // How do the humans at this interface feel about each other?
    const relationshipScore = metrics.crossDomainTrustScore;

    // Factor 5: Mutual understanding
    // Do both sides understand each other's needs?
    const understandingScore = (
        metrics.domainAUnderstandsB + metrics.domainBUnderstandsA
    ) / 2;

    // Weighted combination
    const health = (
        handoffRate * 0.25 +
        cycleScore * 0.20 +
        integrityScore * 0.20 +
        relationshipScore * 0.20 +
        understandingScore * 0.15
    );

    return {
        score: health,
        state: classifyEdgeState(health),
        bottleneck: health < 0.4,
        factors: {
            handoffRate,
            cycleScore,
            integrityScore,
            relationshipScore,
            understandingScore
        },
        recommendation: generateEdgeRecommendation(health, metrics)
    };
}

function classifyEdgeState(health) {
    if (health >= 0.8) return 'symbiosis';
    if (health >= 0.6) return 'flow';
    if (health >= 0.4) return 'gate';
    if (health >= 0.2) return 'friction';
    return 'wall';
}
```

## Bidirectional Edge Flow

### The Two-Way Channel

An edge is not a one-way street. Every edge is a **bidirectional channel** where both faces send AND receive.

```
THE BIDIRECTIONAL EDGE

    ┌─────────────────┐                 ┌─────────────────┐
    │                 │  ═══════════►   │                 │
    │     FACE A      │     EDGE        │     FACE B      │
    │                 │  ◄═══════════   │                 │
    └─────────────────┘                 └─────────────────┘

    A → B: What A GIVES to B (projection)
    B → A: What A RECEIVES from B (reception)

    TOTAL EDGE = A→B + B→A
```

### Directional Edge Metrics

Each direction has its own health:

```javascript
// Future: js/ai/edge/bidirectional-flow.js

/**
 * Edge with bidirectional flow analysis
 */
class BidirectionalEdge {
    constructor(faceA, faceB) {
        this.faceA = faceA;
        this.faceB = faceB;

        // Directional flows
        this.flowAtoB = {
            rate: 0,           // How much flows A → B
            quality: 0,        // Quality of what flows
            latency: 0,        // Time delay
            lossRate: 0        // What's lost in translation
        };

        this.flowBtoA = {
            rate: 0,           // How much flows B → A
            quality: 0,        // Quality of what flows
            latency: 0,        // Time delay
            lossRate: 0        // What's lost in translation
        };
    }

    /**
     * Calculate edge balance
     * Healthy edges have balanced bidirectional flow
     */
    calculateBalance() {
        const aToB = this.flowAtoB.rate * this.flowAtoB.quality;
        const bToA = this.flowBtoA.rate * this.flowBtoA.quality;

        if (aToB === 0 && bToA === 0) return 0;  // Dead edge

        const total = aToB + bToA;
        const balance = 1 - Math.abs(aToB - bToA) / total;

        return {
            balance: balance,           // 0-1 (1 = perfectly balanced)
            netFlow: aToB - bToA,       // Positive = A gives more
            dominant: aToB > bToA ? 'A' : 'B',
            interpretation: this.interpretBalance(balance, aToB - bToA)
        };
    }

    interpretBalance(balance, netFlow) {
        if (balance > 0.8) return 'Healthy reciprocity';
        if (balance > 0.6) return 'Slight imbalance - monitor';
        if (balance > 0.4) return 'Significant imbalance - one side giving more';
        if (netFlow > 0) return 'A is depleting - giving without receiving';
        return 'B is depleting - giving without receiving';
    }

    /**
     * Calculate total edge health
     */
    calculateHealth() {
        const balanceMetrics = this.calculateBalance();

        // Factor 1: Both directions flowing (not blocked)
        const flowScore = Math.min(
            this.flowAtoB.rate > 0 ? 1 : 0,
            this.flowBtoA.rate > 0 ? 1 : 0
        );

        // Factor 2: Quality of flow
        const qualityScore = (
            this.flowAtoB.quality + this.flowBtoA.quality
        ) / 2;

        // Factor 3: Low latency
        const latencyScore = 1 - (
            (this.flowAtoB.latency + this.flowBtoA.latency) / 2
        );

        // Factor 4: Low loss
        const integrityScore = 1 - (
            (this.flowAtoB.lossRate + this.flowBtoA.lossRate) / 2
        );

        // Factor 5: Balance
        const balanceScore = balanceMetrics.balance;

        return {
            overall: (
                flowScore * 0.20 +
                qualityScore * 0.25 +
                latencyScore * 0.15 +
                integrityScore * 0.20 +
                balanceScore * 0.20
            ),
            factors: {
                flow: flowScore,
                quality: qualityScore,
                latency: latencyScore,
                integrity: integrityScore,
                balance: balanceScore
            },
            directions: {
                aToB: this.flowAtoB,
                bToA: this.flowBtoA
            },
            balanceAnalysis: balanceMetrics
        };
    }
}
```

```javascript
// Future: js/ai/edge/flow-analysis.js

/**
 * Analyze flow through an edge chain
 *
 * @param {number[]} faceSequence - Ordered list of face IDs in the chain
 * @param {EdgeHealthMap} edgeHealth - Health scores for all edges
 * @returns {ChainFlowAnalysis} Flow analysis for the chain
 */
function analyzeChainFlow(faceSequence, edgeHealth) {
    const edges = [];
    let bottleneckIndex = -1;
    let minHealth = 1.0;

    // Analyze each edge in the chain
    for (let i = 0; i < faceSequence.length - 1; i++) {
        const fromFace = faceSequence[i];
        const toFace = faceSequence[i + 1];
        const edgeKey = `${Math.min(fromFace, toFace)}-${Math.max(fromFace, toFace)}`;
        const health = edgeHealth[edgeKey]?.score || 0;

        edges.push({
            from: fromFace,
            to: toFace,
            health: health,
            state: classifyEdgeState(health)
        });

        if (health < minHealth) {
            minHealth = health;
            bottleneckIndex = i;
        }
    }

    // Chain throughput limited by weakest edge
    const chainThroughput = minHealth;

    // Calculate cumulative loss
    const cumulativeThroughput = edges.reduce((acc, e) => acc * e.health, 1.0);

    return {
        edges: edges,
        chainThroughput: chainThroughput,
        cumulativeThroughput: cumulativeThroughput,
        bottleneck: bottleneckIndex >= 0 ? edges[bottleneckIndex] : null,
        recommendation: generateChainRecommendation(edges, bottleneckIndex)
    };
}

/**
 * Identify all critical paths in the organization
 */
function identifyCriticalPaths(edgeHealth) {
    const criticalPaths = [
        {
            name: 'Viability Circuit',
            faces: [1, 3, 8, 5, 11, 1],  // Financial → Human → Operations → Market → Funding → Financial
            priority: 'existential'
        },
        {
            name: 'Innovation Loop',
            faces: [3, 2, 7, 5, 9, 3],  // Human → Intellectual → Brand → Market → Regenerative → Human
            priority: 'growth'
        },
        {
            name: 'Trust Chain',
            faces: [10, 3, 7, 5],  // Values → Human → Brand → Market
            priority: 'reputation'
        }
    ];

    return criticalPaths.map(path => ({
        ...path,
        analysis: analyzeChainFlow(path.faces, edgeHealth)
    }));
}
```

After reflection, we realized:

1. **Forced complexity** - Assigning fixed elemental natures to edges required solving an arbitrary orientation puzzle (which edge is "Earth"?)
2. **The breath axis approach felt forced** - Using breath axis direction as "north" to determine orientation didn't land naturally
3. **Elements already live in faces** - Each face already has its 5 elements mapped to its KPIs; the edge doesn't need its own
4. **Intellectual beauty ≠ organic truth** - The model was mathematically interesting but didn't feel alive

### The Simpler Alternative

The edge is simply a **membrane** - its character emerges dynamically from the relationship between the two faces it connects, not from an inherent assignment.

### What Was Valuable

Some concepts from this exploration remain useful:
- **Face element synergies** - Comparing element strengths across faces is still valid
- **Element harmony patterns** - Understanding how different elemental energies interact still applies at the face-to-face level
- **Star-pair insights** - The pentagram star-pairs remain meaningful within each face

### The Original Ideas (For Reference)

The exploration proposed:
- Each of a face's 5 edges governed by Earth, Water, Fire, Air, or Ether
- An Element Harmony Matrix showing how elements interact at edges
- Orientation systems using vertices and breath axes to determine element placement
- Cross-face element resonance calculations

These are preserved in git history for potential future reference, but the main document now reflects the simpler, more organic model.
