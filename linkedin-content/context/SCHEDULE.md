# LinkedIn Posting Schedule

## Weekly Rhythm

| Day | Content Type | Focus | Target Audience |
|-----|--------------|-------|-----------------|
| **Monday** | Philosophy Post | Paradigm shift, teaching new understanding | Organizational leaders, Founders, Systems thinkers |
| **Wednesday** | Feature Update | Technical progress, new capabilities, beta testing | Developers, Product people, Early adopters |

## Why This Spacing?

- **Monday** - Start the week with inspiration, set the tone with deeper "why"
- **Wednesday** - Mid-week, high engagement, concrete "what we built"
- **4-day gap** - Gives each post room to breathe, weekend in between

## Post Checklist

### Before Writing:
- [ ] Read `LINKEDIN_PIPELINE_SOUL.md` to remember the context
- [ ] Check git log for recent changes (`git log --oneline -20`)
- [ ] Note any new features or significant progress
- [ ] Consider what screenshots would be valuable

### Feature Update Posts (Wednesday) Should Include:
- [ ] What was built/fixed/improved
- [ ] Why it matters (connect to bigger picture)
- [ ] Screenshot(s) of the feature in action
- [ ] Call to action (beta testing, feedback, etc.)
- [ ] Relevant hashtags

### Philosophy Posts (Monday) Should Include:
- [ ] A compelling opening hook
- [ ] The paradigm shift being proposed
- [ ] A concrete example or metaphor
- [ ] Connection to Quannex vision
- [ ] Invitation for dialogue
- [ ] Relevant hashtags
