# Data Archive

This folder contains the original MVP/proof-of-concept CSV files before any modifications or enhancements.

## Purpose

- **Historical reference** for the original vision and ideation
- **Comparison point** for understanding how the system has evolved
- **Recovery source** if needed for any reason
- **Honoring the seed** - these files represent the first crystallization of a sophisticated vision

## Philosophy

The files in this archive represent the *seed* from which the dodecahedron organizational assessment model grew. They were manually created with care and intention, even if they contain gaps or simplifications. We preserve them not because they are perfect, but because they are meaningful.

## Files

### CSV_Face_Models_v1_original.csv
- **Original purpose**: Pentagramic analysis of the 12 organizational faces
- **Created**: During initial ideation phase
- **Note**: Face 12 energy value (0.19633) differs from CSV_Dodeca_Engine.csv (0.2690781)
- **Status**: Superseded by CSV_Dodeca_Engine.csv for face energy calculations

## Usage

**These files should NOT be loaded by the application.**

They exist purely for:
1. Reference and historical documentation
2. Understanding the evolution of the data model
3. Recovery if something goes wrong with working files

## Current Working Files

The application uses files in the parent `data/` directory:
- `CSV_Dodeca_Engine.csv` - Authoritative source for face data
- `CSV_BREATH_RATIOS.csv` - Octave and breath axis definitions
- `CSV_Refrence_Models.csv` - 420 KPI templates
- `CSV_Edge_tension_Map.csv` - Edge definitions
- `CSV_Vortex_Map.csv` - Vertex definitions
